1.2.2 Category spelling / homogeneity check

check_spelling_homogeneity() flags pairs of values in a column that are identical after trimming/casefolding (“case_or_whitespace” - safe to auto-fix) or within a small edit distance (“possible_typo” - needs a human read).

Tolerance differs by column: Production/Species are free text, so a 1-2 character difference is almost always a typo (max_dist = 2); ST/ Serotype are nomenclature codes where a 1-character difference is usually a genuinely different code (O1:H4 vs. O1:H7), so only exact case/whitespace collisions are flagged (max_dist = 0). Moreover those should be automatically assigned so it should not be any errors

  • keeping the top 5 variants covers 417/884 isolates (47.2%) but names only 5/88 STs (5.7%) and 5/115 serotypes (4.3%) - the “other” bucket is the minority of isolates (467, 52.8%) yet holds nearly all of the diversity (97.7% of STs, 99.1% of serotypes).

  • Top 10 covers more isolates (550/884, 62.2%) at a similar diversity trade-off - 8 STs (9.1%) and 10 serotypes (8.7%) named, 94.3%/95.7% still in “other”. Neither threshold captures much ST/Serotype diversity - that’s inherent to a “top N” cut on data this skewed (one variant, ST23-O78:H4, is 244/884 isolates - 27.6% - on its own), not a flaw in the threshold choice.

Pie size uses 4 fixed categories (1-10, 10-50, 50-100, 100-200 isolates) instead of a continuous scale, so sizes are easy to compare at a glance. Each category gets one area-corrected radius (sqrt, not linear - a linear radius would make circle area, which is what a reader actually perceives, grow with the square of the count and exaggerate differences).
